# Instruções de implementação — G3 Vison

## Objetivo

Implementar a tablist principal Montagem/Visualização. Montagem contém tree-panel + inspector-panel e é inicial. Visualização contém output-panel + code-panel lateral. Remover Preview/Code internos.

## Referência

- Análise: 6_AN_20260925-025932.md
- Estado: Não iniciado

## Restrições

- Uma única tablist e exatamente duas tabs.
- Uma única instância de #preview, #code e #messages.
- #code continua atualizado somente por SchemaView.renderCode().
- Não alterar modelo, schema, geração, persistência, URL, backend ou JSON.
- Preservar árvore/expansão, seleção, edição, drag/drop, ações e atalhos.
- Remover data-tab e a lógica legada Preview/Code.

## Comandos

Na raiz do Vison:

    npm test
    npm run check
    node tests/run-tests.mjs
    npm start

Usar npm start somente para QA manual; registrar viewport desktop/mobile, foco, teclado e ausência de overflow. Não declarar QA visual apenas pelos testes Node.

## Gate G3 operacional

Pontos autorizados: index.html, css/style.css, js/controllers/app-controller.js, js/i18n.js e testes. SchemaView só pode ser alterada mediante necessidade comprovada, preservando renderCode/renderPreview/renderTree.

Entrega esperada: diff, testes verdes, matriz CA-01..CA-16 preenchida, evidência de teclado/ARIA e desktop/mobile, confirmação de ausência de mudança em modelo, persistência, geração e expansão.
