# Instruções de implementação para IA — G3 Vison

## Objetivo

Construir a primeira versão executável do Vison como aplicação estática em HTML/CSS/JS puro, mantendo separação MVC, documento hierárquico validado por JSON Schema, histórico undo/redo, localStorage, import/export e UI responsiva/acessível.

## Referência

- Análise humana: `3_AN_20260924-013006.md`
- Estado: Não iniciado

## Restrições obrigatórias

- Não adicionar backend, autenticação, framework ou API sem autorização.
- Não inventar regras de domínio além do schema mínimo; deixar tipos/campos extensíveis e registrar pendências.
- Não executar conteúdo importado; usar somente texto e dados validados.
- Não usar `innerHTML` para valores vindos do documento.
- Não marcar etapas como concluídas sem evidência objetiva.
- Preservar o mesmo contrato de dados em import/export e versionar migrações.
