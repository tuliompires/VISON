# Instruções de implementação para IA

## Objetivo

Adicionar à árvore do Vison um controle por nó com filhos para expandir/recolher exclusivamente seus filhos diretos, preservando dados e comportamentos existentes.

## Referência

- Análise humana: `4_AN_20260925-003948.md`
- Estado: Não iniciado
- Prioridade operacional: média

## Restrições obrigatórias

- Não alterar o schema JSON nem persistir o estado visual de expansão.
- O toggle de um nó pode afetar somente o container de `children` desse nó.
- Não adicionar comportamento de expansão/recolhimento para netos como efeito colateral.
- Preservar seleção, edição, drag-and-drop, undo/redo, importação, exportação e acessibilidade existente.
- Não modificar arquivos fora do escopo sem justificar no registro de conclusão.
